原生 Linux XTW-5 编程器开发预览版，Qt 6 Widgets + libusb，无需 Wine。

- 自动连接 / 热插拔检测、芯片识别、芯片库导入、十六进制编辑、读写 / 擦除 / 校验。
- 当前 C84017 芯片（GD25Q64C 参数）完成 8 MiB 实机擦写和独立读取比对，原内容已恢复。
- 修复实机响应解析、特殊页大小对齐、弹窗期间自动连接冲突；写入后强制回读校验。
- 所有构建运行协议及 GUI 离线测试，并对 tar.gz 执行模拟启动检查。

请选择匹配发行版的 x86_64 包；tar.gz 仍需系统 Qt 6、libusb、OpenSSL 运行库。安装说明见仓库 docs/distribution.md。SHA256SUMS 用于核对下载完整性。

首次使用须导入自己的芯片库；不包含厂家软件、数据库或固件备份。
尚未实机验证其他型号、EEPROM、1.8 V、第二插座和操作中物理拔插。AT45、SPI NAND、双插座并行、脱机项目和固件升级未实现。此版本为预发行版。
